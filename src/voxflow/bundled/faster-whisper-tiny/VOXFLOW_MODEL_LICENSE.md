# Bundled model license

This directory contains `Systran/faster-whisper-tiny` from Hugging Face:

https://huggingface.co/Systran/faster-whisper-tiny

The model card identifies the model license as MIT and describes it as a
CTranslate2 conversion of `openai/whisper-tiny`.

The bundled copy is included so VoxFlow has a small offline fallback model for
source checkouts and lightweight installs. Higher-accuracy models can be
downloaded with `voxflow models`.
