# 实施计划

> **编号** VF-ENG-02 · **版本** 0.4 · **状态** 评审中(进度注记已并入) · **最后更新** 2026-06-10

**进度跟踪**:阶段执行记录见 `docs/release/stage-*.md`,任务清单见仓库根目录 `todo.md`;本文档只定义阶段与退出条件,不重复记录进度。

**执行方式注记(2026-06-10)**:实际执行采用"广度优先铺骨架"——阶段 2-6 的离线可测骨架(抽象层、适配器、数据集工具、静态原型)已并行建立,这是允许的;但**阶段退出仍必须串行**:每阶段的人工验证点未签字前不得宣布该阶段完成,go/no-go 复审点(阶段 3)不因骨架先行而提前或跳过。

按 D-7 裁决,本计划不再是"迁移"计划:**旧 Python 0.2.0 版本直接废弃,不保留、不归档运行版本(git 历史自然保留),无旧版用户、无数据迁移负担**。新版从零按本文档库实现。

按 D-10 裁决,项目背景为**个人项目、完全由 AI agent(Claude Code)开发**:编码与自动化测试由 agent 完成,日历工期不按全职工程师周估算,而由**所有者的人工验证带宽**决定。因此本计划以"阶段 → 退出条件 → 人工验证点"组织,不设硬日历承诺。

## 0. 协作模型

| 角色 | 职责 |
| --- | --- |
| 所有者 | 决策、真实环境人工验证(麦克风/桌面/真实应用)、数据集标注复核、发布批准 |
| AI agent | 设计落地、编码、单元/集成测试、文档同步、按退出条件自检 |

工程纪律(防止 AI 开发的规范漂移):

1. 冻结文档是唯一实现依据;任何偏离必须先改文档(见 [Git 工作流 §5](git-workflow.md))。
2. 每个 PR 必须:关联需求/决策编号、agent 自测记录、CI 全绿;行为可见的变更附人工验证步骤说明,供所有者快速复核。
3. agent **无法直接验证**的事项显式标记为人工验证点:真实麦克风延迟与体验、各桌面会话下的输入法/指示器表现、安装包在真机的行为。
4. 阶段退出条件中的自动化项由 CI 判定,人工项由所有者确认后在阶段记录中签字(commit 留痕)。

## 2. 各阶段定义

### 阶段 0:文档冻结与决策

- 内容:[D-1~D-16](../review-and-decisions.md) 裁决回填(已完成);所有者确认后全库转"已冻结"。
- 退出:无开放决策;仓库结构按 D-11 就绪(Rust workspace 建立,Python 实现删除)。
- 人工验证点:决策清单最终签字。

### 阶段 1:Rust Core 原型

- 内容:workspace 搭建;daemon 启动/单实例/优雅退出;IPC 服务端(握手、订阅、core.status、config.get/update)+ 机器可读 schema;配置与日志;MockRecognizer 输出 partial/stable/final 流。
- 退出(自动化):IPC 集成测试全绿;CLI 可驱动 mock 听写会话。不接 UI、不接真实模型。
- 人工验证点:CLI 演示走查一次(所有者了解形态即可)。

### 阶段 2:IBus 原型

- 内容:component 注册;引擎进程连 Core;preedit/commit/delete 跑通;焦点与能力上报;preedit 无占位文案断言(FR-INP-10)。
- 第 1 批次为 D-2 POC 检查点:zbus 路线受阻即切 C shim。
- 退出(自动化):虚拟会话引擎测试全绿。(人工)GNOME 会话中 Text Editor + Chrome 由 mock 链路驱动可输入;降级矩阵可演示。
- 人工验证点:真实 GNOME(Wayland 与 X11 各一次)preedit/commit 行为走查。

### 阶段 3:真实流式 ASR(go/no-go)

- 内容:PipeWire 音频帧采集;silero VAD;接入 D-1 选定模型(双候选并行 POC);token 稳定策略调参;延迟埋点与基准报告。
- 退出(自动化):基准机回放测试首 partial < 500 ms (p90)、stable commit < 1000 ms (p90);10 分钟回放稳定。(人工)真实麦克风连续听写体验可接受。
- 人工验证点:真实麦克风听写(中文、英文、中英混说各一段);主观延迟与准确率评价。**未达标触发 go/no-go 复审**(换模型/调预算/调目标)。

### 阶段 4:Tauri 控制台 + 状态指示器

- 内容:ipc-bridge;八个页面;主题系统;托盘;**状态指示器窗口**(X11 定位 + layer-shell POC + GNOME 托盘降级,FR-CC-11)。
- 退出(自动化):UI 测试全绿;指示器四态切换 < 100 ms。(人工)三种桌面环境指示器档位正确。
- 人工验证点:GNOME Wayland(托盘档)、X11(HUD 档)、KDE Wayland(layer-shell 档)各走查一次;主题三态走查。

### 阶段 5:语义撤销

- 内容:账本与冻结策略;规则状态机;数据集构建(≥ 1500 条,agent 生成 + 所有者抽样复核);分类器训练与 ONNX 导出;安全门;修正记录与恢复;语义修正页。
- 退出(自动化):冻结测试集过发布门(macro F1 ≥ 0.85、误删指标达标);分类器失败规则兜底;可整体关闭。
- 人工验证点:数据集抽样复核(≥ 10% 样本);真实听写中"不对,四点"/"这不是问题"等关键场景实测。
- 裁剪预案:数据集/训练超期时按 [PRD §8] 规则状态机先行,分类器转 P0.5。

### 阶段 6:Fcitx5 前端(D-15)

- 内容:薄 C++ addon(协议翻译,连 Core);addon/inputmethod 配置;与 IBus 共用验收用例;`install-fcitx5` 脚本。
- 退出(自动化):引擎测试套件在 Fcitx5 下全绿。(人工)KDE Plasma Wayland 会话真实应用 smoke。
- 人工验证点:KDE 会话走查(Kate、Chromium、Konsole)。

### 阶段 7:打包发布(MVP)

- 内容:单一 deb + portable;systemd user unit;install 脚本族;容器包测试矩阵;发布检查单;README。
- 退出:[PRD §7 MVP 验收清单](../product/prd.md) 9 项全部通过;首个新版版本号发布(建议 `0.3.0`)。
- 人工验证点:至少一台真机(所有者日常机)deb 安装→听写→卸载全流程;portable 任意目录走查。

### 阶段 8:跨平台预研(可与 5-7 并行)

- 内容:macOS IMK spike、Windows TSF 调研,回填[平台文档](../platforms/macos.md)的问题清单。
- 退出:预研报告回填,P1 排期依据成立。

## 3. 旧版处置(D-7 裁决)

- Python 实现(`src/voxflow/`、相关脚本与打包文件)在阶段 0 仓库重组时**直接删除**,不迁入 `legacy/`;历史经 git 追溯。
- 无旧版用户:不做配置兼容、不做数据迁移、不保留过渡版本。
- AGENTS.md 在仓库重组同批次更新为新架构约定(验证命令、目录结构、开发约束)。
- 可复用的**资产**(非代码):语义撤销负例样本、文档中的诊断经验(蓝牙 profile 等)、设计资产,按需摘入新实现。
