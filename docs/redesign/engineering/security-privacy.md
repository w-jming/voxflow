# 安全与隐私

> **编号** VF-ENG-04 · **版本** 0.2 · **状态** 评审中 · **最后更新** 2026-06-10

对应需求:NFR-PRV-01~05。

## 1. 威胁模型(轻量)

本地单用户桌面软件;不设网络服务端口;唯一外联是模型下载。

| 资产 | 威胁 | 缓解 |
| --- | --- | --- |
| 用户语音/文本 | 意外上传、日志泄漏 | 默认零上传;日志脱敏(§3);诊断摘要脱敏 |
| IPC 通道 | 同机其他用户进程接入 | socket 目录 0700,仅本用户可连(NFR-PRV-04) |
| 模型文件 | 供应链污染、恶意权重 | 仅 profile 声明来源 + sha256 逐文件校验;不执行模型目录中的任何脚本 |
| 配置/账本 | 篡改、含敏感内容 | 用户目录权限;账本默认仅内存 |
| 仓库/发布物 | secret 泄漏 | 提交与发布前 secret scan(§5) |

## 2. 默认本地

VoxFlow 默认不上传:音频、识别文本、日志、模型使用记录(无遥测)。任何云端能力(P2 可选后端)必须显式启用,清楚展示数据去向,并在 UI 常驻可见状态标识。

## 3. 权限与日志

最小权限:麦克风、输入法注册、用户目录读写;Core 不以 root 运行,deb 安装不引入 setuid。

日志规则:

- 默认不记录完整输入文本;识别内容在日志中截断脱敏(只留长度与哈希)。
- 调试模式可记录更多,但必须:用户显式开启、明确提示隐私风险、可一键关闭、可一键清理。
- 诊断摘要复制时自动隐藏 token、私钥、用户文本、路径中的用户名。

## 4. 模型下载安全

- 只从 profile 声明的来源下载;重定向到未知域即中止。
- 逐文件 sha256;临时目录下载完成并校验后原子移动;校验失败不激活、不残留。
- 本地导入无 manifest 时显著标注"未校验来源"。
- 不执行模型目录中的任意脚本或动态库加载之外的代码路径。

## 5. secret 管理

仓库与发布物禁止包含:API key、token、私钥、真实用户日志、音频样本、大模型权重(除非许可证、体积和项目规则明确允许)。

- 提交前与发布前执行 secret scan(gitleaks 或等价工具),纳入 CI 必过门(见[测试策略 §7](testing-strategy.md))。
- 提交身份遵循项目约定;不得把本机路径、私密日志推送到远程(同 [Git 工作流](git-workflow.md))。
