# 控制台详细规格

> **编号** VF-DSN-04 · **版本** 0.3 · **状态** 评审中(决策已回填,待冻结) · **最后更新** 2026-06-10

视觉规范见 [UI 系统](ui-system.md);数据来源与命令见 [IPC API](../architecture/ipc-api.md);页面状态全部由 Core 事件驱动(见 [Tauri 控制台 §5](../frontend/tauri-ui.md))。

## 1. 总览

控制台首页必须回答四个问题:

1. VoxFlow 输入服务是否运行。
2. 当前应用能否使用 VoxFlow 输入。
3. 麦克风是否可用。
4. 当前模型是否可用。

参考线框图:[control-center-wireframe.svg](assets/control-center-wireframe.svg)。

每个页面统一具备四种渲染态:**加载**(骨架,尺寸与就绪态一致)/ **就绪** / **空**(必须带下一步操作)/ **错误**(具体原因 + 重试或诊断入口)。

## 2. 全局框架

### Header

- VoxFlow Logo(随主题切换资产)。
- 全局状态膘:`可输入` / `需要处理` / `错误`(聚合各状态卡片,取最严重级)。
- 当前模型名。
- 快速操作:暂停听写、打开日志、更多菜单(含主题快捷切换、退出)。

### Sidebar(220px)

导航顺序:总览、输入、模型、音频、语义修正、数据、诊断、外观。当前项使用选中态底色(`--vf-primary-100` / 深色 `--vf-primary-900`),左侧 3px 主色指示条。

### Content

内容区最大宽 920px;页面顶部放主状态,下方放具体设置。

## 3. 总览页

2 列状态卡片(组件规格见 [UI 系统 §4.1](ui-system.md)):

| 卡片 | 内容 | 操作 |
| --- | --- | --- |
| 输入服务 | 运行中/已停止/崩溃/连接中 | 启动、停止、重启 |
| 输入法前端 | 平台对应注册与激活状态、能力档位(完整/仅提交/受限撤销/兼容注入) | 安装/刷新、打开系统输入源设置 |
| 麦克风 | 当前设备、电平、权限、蓝牙 profile | 录音测试、打开系统声音设置 |
| 模型 | 当前 ASR 模型 + 语义分类器;可用/加载中/缺失/校验失败 | 切换、下载、校验 |

卡片下方:最近一次错误(可展开详情)、快速操作行(开始/停止服务、打开诊断、打开日志)。

## 4. 输入页

| 设置项 | 控件 | 说明 |
| --- | --- | --- |
| 输入模式 | 单选 | 输入法模式(推荐)/ 兼容注入模式(标注风险) |
| 快捷键 | 录入组件 | 见 [UI 系统 §4.4](ui-system.md);默认值见 [D-14](../review-and-decisions.md) |
| 按键逻辑 | 单选 | 按住说话 / 按一次开始再按一次停止 |
| 输出字形 | 单选 | 简体 / 繁体 / 模型原文 |
| 光标处反馈 | 状态 + 开关 | 显示当前生效方式,如"正在使用 IBus preedit 显示临时文本";降级时说明原因 |
| 状态指示器 | 开关 + 位置(四角)+ 显示时机(仅听写时/常驻) | HUD 不可用环境(GNOME Wayland)显示"已降级为托盘状态"说明,见[交互设计 §1.1](../frontend/interaction-design.md) |
| 自动标点 | 开关 | |
| 口语助词清理 | 开关 | |

## 5. 模型页

分区:当前模型 → 推荐模型 → 已安装 → 可下载 → 本地导入。

- 模型类型三类:实时流式 ASR、高准确率精修 ASR、语义撤销分类器。
- 模型卡片必须显示许可证;无许可证的模型不得进入稳定版推荐列表(FR-MDL-06)。
- 下载中卡片展开进度区(见 [UI 系统 §4.3](ui-system.md));删除需二次确认并显示释放空间。
- 本地导入:选择目录 → 校验清单逐项打勾/打叉 → 复制或软链接 → 完成。

## 6. 音频页

设备选择(含蓝牙 profile 标注)、实时电平条、VAD 灵敏度、录音测试(开始/停止/回放)、蓝牙诊断(见 UJ-08)、采样率与声道状态。录音测试结果保存短期状态,默认不保存用户音频文件(NFR-PRV-01)。

## 7. 语义修正页

- 智能撤销总开关(FR-SEM-06)。
- 分类器状态卡:可用 / 加载中 / 已降级为规则 / 缺少模型 / 加载失败,附版本号。
- 阈值模式:保守 / 标准 / 积极(说明文案解释差异)。
- 最近修正记录列表(组件见 [UI 系统 §4.6](ui-system.md))+ 恢复上一条。
- 误触发反馈入口。
- 普通用户只看到可用后端;实验后端进入开发者模式(FR-SEM-09)。

## 8. 数据页

- 显示 VoxFlow Home、模型、日志、缓存四个目录及占用空间,均可"打开文件夹"。
- 目录迁移向导(流程见[交互设计 §5](../frontend/interaction-design.md)),支持只迁移配置、不迁移模型。
- 清理缓存(显示可释放空间,二次确认)。

## 9. 诊断页

- 一键 doctor(`diagnostics.run`):结构化结果按 通过/警告/失败 分组,每项附修复建议。
- 复制诊断摘要(自动脱敏:隐藏 token、私钥、用户文本、路径中的用户名,见 NFR-PRV)。
- 打开日志、查看输入法组件状态、模型校验结果、平台权限。

## 10. 外观页

- 主题:跟随系统 / 浅色 / 深色(即时生效,不重启 Core,不中断输入会话)。
- Logo 预览:浅色版与深色版并排。
- 动效:标准 / 减少动效。
- 高对比度提示(检测系统高对比度设置时给出说明)。

实现规范见[主题系统](theme-system.md)。

## 11. 空状态与错误一览

| 场景 | 文案方向 | 主操作 |
| --- | --- | --- |
| 没有模型 | "还没有可用模型" | 下载推荐模型 / 导入本地模型 |
| 输入法未注册 | "输入法组件未注册" | 安装输入法组件 |
| 麦克风不可用 | "未检测到可用输入设备" | 打开音频设置 / 重新检测 |
| 分类器不可用 | "智能撤销已降级为规则模式" | 重新校验 / 查看说明 |
| Core 未连接 | "核心服务未连接" | 重启服务 / 查看日志 |

错误文案面向用户陈述影响与下一步,堆栈细节折叠进"详情"。
