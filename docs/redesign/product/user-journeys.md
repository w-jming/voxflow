# 用户旅程

> **编号** VF-PRD-03 · **版本** 0.3 · **状态** 评审中(决策已回填,待冻结) · **最后更新** 2026-06-10

每个旅程包含前置条件、期望体验和成功标准。成功标准是人工验收(MT)的依据,对应需求编号见各节标注。

## UJ-01 首次安装

**前置**:用户下载 deb 或 portable 包,系统为受支持的 Linux 发行版。
**关联**:FR-PKG-01/02、FR-CC-01。

安装后应用菜单出现"VoxFlow / 声流输入法"。首次打开控制台,用户在总览页立即看到:

- 输入服务是否运行。
- 输入法前端是否已注册。
- 麦克风是否可用。
- 模型是否可用。
- 下一步需要做什么(每个异常状态卡片附带主操作按钮)。

如果 IBus 未启用,控制台提供"安装/刷新输入法组件"和"打开系统输入源设置"入口。错误信息面向用户,不以底层堆栈作为主文案。

**成功标准**:不阅读文档的新用户能在 5 分钟内完成首次听写,或明确知道被哪一步阻塞。

## UJ-02 第一次听写

**前置**:UJ-01 完成,输入法已注册。
**关联**:FR-INP-02/03/04、FR-INP-05、FR-CC-11。

用户把光标放到浏览器搜索框,切换到 VoxFlow 输入法或按快捷键(默认 `Alt+S`):

- 屏幕角落的全局状态指示器立即(< 100 ms)切换为"听写中",并显示实时电平。
- 说话后,临时文本在光标处逐步出现并随识别修正;preedit 中只出现真实识别文本,无任何占位文案。
- 稳定文本自动 commit 到输入框。
- 系统通知不弹出"开始录音""正在识别"等过程性内容。
- 仅无语音、麦克风失败、模型失败等异常才出现通知或控制台告警。

**成功标准**:全程无系统通知;指示器状态实时正确;partial 可见;stable 文本与最终语义一致。

## UJ-03 长时间连续听写

**前置**:UJ-02 可用。
**关联**:FR-INP-01、NFR-PRF-03。

用户连续口述一段文章(≥ 10 分钟):

- 音频采集不中断,partial 持续更新。
- stable 按短语或标点边界 commit。
- 控制台可显示实时状态但不抢焦点。
- 日志保存在用户目录,可从控制台打开。

**成功标准**:10 分钟无中断、无状态丢失;Core 内存无持续增长。

## UJ-04 自然修正

**前置**:智能撤销开启。
**关联**:FR-SEM-02~05。

用户说:`今天下午三点开会,不对,四点`

- "今天下午三点开会"先正常输入。
- "不对,四点"被识别为 replace_entity 意图。
- 根据账本定位最近可替换目标,只把"三点"替换为"四点"。
- 不删除用户手动输入的内容。
- 控制台"最近修正记录"可看到此次修正及置信度。

用户说:`这不是问题`

- 原样输入,不触发撤销。

**成功标准**:替换精确到目标实体;负例零误触发。

## UJ-05 关闭语义撤销

**关联**:FR-SEM-06。

用户在控制台关闭"智能撤销"。之后"不是""不对""删掉"等均按普通文本处理。设置保存后 Core 立即生效,无需重启任何组件。

**成功标准**:关闭后负例与正例均原样输入;重新开启后能力恢复。

## UJ-06 模型下载

**关联**:FR-MDL-02/04/06。

用户打开"模型"页,选择高准确率模型。页面必须显示:模型名称、参数规模、许可证、下载来源、目标目录、总大小、已下载大小、速度、预计剩余时间,以及暂停/继续/取消按钮。

下载完成后自动校验;校验失败的模型不能被切换为当前模型,且页面给出失败原因和重试入口。

**成功标准**:断网后恢复可续传;校验失败不影响现有可用模型。

## UJ-07 本地模型导入

**关联**:FR-MDL-03/04。

用户已有 Qwen 等支持的模型权重,选择"导入本地模型",可选复制或软链接。导入前校验:目录结构、配置文件、tokenizer/processor、权重文件完整性、manifest checksum、最小 smoke test。

**成功标准**:任一校验失败时,当前可用模型与配置完全不受影响,并显示具体失败项。

## UJ-08 蓝牙耳机问题

**关联**:FR-CC-10。

用户连接蓝牙耳机但无法输入。控制台"音频"页显示:

- 当前默认输入设备。
- 蓝牙 profile 是否为仅输出(A2DP)。
- 是否存在 hands-free/headset 输入源。
- 可执行的修复建议:系统允许时提供一键切换 profile 按钮,否则提供系统设置入口。

**成功标准**:用户不查文档即可理解"耳机连上了但没有麦克风"并完成修复。

## UJ-09 退出

**关联**:FR-CC-07/08。

用户从托盘菜单操作,界面明确区分三个层级:

| 操作 | 效果 |
| --- | --- |
| 关闭控制台窗口 | 仅关闭 UI,Core 与听写不受影响 |
| 停止输入服务 | Core 停止听写能力,托盘与 UI 保留 |
| 退出 VoxFlow | Core、输入监听、模型任务、托盘全部停止 |

**成功标准**:退出后无残留进程,不再弹出任何录音提示;再次启动状态干净。
